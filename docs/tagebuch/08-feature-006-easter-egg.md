# 08 · Feature 006: Easter egg 01, the hidden game (2026-10-27 to 2026-10-28)

Three grey keys on the communicator's case, pressed left, middle, right, start a small shoot-'em-up
on the device's LCD. The feature also brings the first sound into the game. Checklist 34 points,
analysis 32 findings, seven phases, the last one from a gap search after the build.

**Tokens and cost:** 2026-10-27 to 2026-10-28 on `feature/006-easter-egg-space-invaders`: 0.9 M output, 1,804 input, 3.6 M cache write, 179.3 M cache read; 367 responses from Claude, 448 from sub-agents; about $75 at API list price.

### 2026-10-27 · The hidden game runs on the device's display `[Game content]`

- **Decision:** The game is a page on the communicator's LCD, 320 × 160, like a handheld game of
  the eighties. Title image, logo and device stay where they are.
- **Alternatives:** Full screen, which needs its own scene and the device sliding out; the display
  with a zoom, which is a new movement and breaks the pixel raster.
- **Why:** The device is already there. A page needs no new scene, and the game stays on the raster.
- **Evidence:** `ccc9db3`, `specs/006-easter-egg-space-invaders/spec.md` (Clarifications, Specify).

### 2026-10-27 · Secret keys that give nothing away `[Game content]` `[Graphics]`

- **Decision:** The three grey keys under the display can be pressed with the mouse. They sink in
  and click, but the pointer stays an arrow and nothing lights up, no tooltip, no focus. The pressed
  look is cut from the case image itself, one image pixel lower. No new image, no new colour.
- **Alternatives:** No reaction at all, which leaves you guessing whether a click hit; the hand
  pointer, which gives the secret away; a second case image with pressed keys.
- **Why:** The keys are part of the picture and a secret. Anything that shows them on hover would
  take the secret away.
- **Evidence:** `ccc9db3`, `f79af16`, `specs/006-easter-egg-space-invaders/research.md` (R3, R4).

### 2026-10-27 · Pixel patterns in one colour, not images `[Graphics]`

- **Decision:** Aliens, cannon, shots and explosions are small pixel patterns written in code, in a
  single colour, `tusche` on `lcd`. They are our own designs, not copies of the original.
- **Alternatives:** Sprite images as PNG, which need rastering and a prompt log; images from
  Leonardo, which handles tiny figures badly.
- **Why:** An LCD can show only one colour, and patterns this small are quicker to write than to
  generate.
- **Evidence:** `ccc9db3`, `d83a6fc`, `src/scenes/title/invaders/invaders_sprites.gd`.

### 2026-10-27 · Sound arrives, generated by a script `[Tools]` `[Architecture]`

- **Decision:** Sound is planned for the game anyway, so this feature introduces it. A Python
  script in the repository generates short square-wave sounds, like a pocket device of 1991, and
  writes them as WAV files. The game has two buses, `Master` and `Effekte`, at a fixed, quiet
  volume until there is a settings menu. The title menu stays silent; only the case keys click.
- **Alternatives:** Computing sounds at run time, which is harder to test and to listen to first;
  a free sound library, which needs downloads and a licence list; no separate buses, which would
  make the later settings touch every sound source.
- **Why:** The script makes every sound reproducible byte for byte, and a test checks the checksums.
- **Evidence:** `0b8405e`, `d6c7fe8`, `tools/ton/make_sounds.py`, `src/default_bus_layout.tres`.

### 2026-10-27 · "GAME OVER", the only English line `[Game content]`

- **Decision:** Both defeats read "GAME OVER", without a full stop, as on the arcade cabinet of
  1978, which was only sold with English texts in Germany. A win reads "ALLE ERWISCHT.".
- **Alternatives:** "DIE SIND GELANDET.", which sounds odd in German, a translation of "they have
  landed"; "SIE SIND GELANDET.", the recommendation; "GELANDET.".
- **Why:** "Game over" counts as a computer word of the time.
- **Evidence:** `d6c7fe8`, `specs/006-easter-egg-space-invaders/spec.md` (Clarifications, Phase 2).

### 2026-10-27 · The game core knows no nodes `[Architecture]`

- **Decision:** The game runs as a plain object with a fixed step of 1/60 s and its own seeded
  random generator. It returns what happened instead of sending signals. The page around it only
  feeds in keys, catches up at most four steps per frame and draws.
- **Why:** That way, a whole game can be played in a test in milliseconds, with the same bombs
  every time; how long a win or a landing takes was measured, not guessed.
- **Evidence:** `d83a6fc`, `0c67387`, `src/scenes/title/invaders/invaders_game.gd`.

### 2026-10-28 · A gap search after the build `[Workflow]`

- **Decision:** After the last build phase, `/speckit-converge` compares spec, plan and tasks with
  the code, together with both reviewer agents over the whole feature. What it finds becomes an
  extra phase.
- **Why:** The code met every requirement, but documents had drifted, three edge cases had no test
  and two comments were wrong. The style reviewer even caught a comment that the fix had made wrong
  in a new way.
- **Evidence:** `c713df5`, `specs/006-easter-egg-space-invaders/tasks.md` (Phase 7),
  `docs/ki_workflow/ki_pruefung.md`.

### 2026-10-28 · Every acceptance request says how to start the app `[Workflow]`

- **Decision:** Any request for my acceptance, including the final one for a whole feature, starts

- **Why:** The rule already existed, but the final acceptance of this feature came without it.
