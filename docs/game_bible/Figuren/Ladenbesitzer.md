# Der Ladenbesitzer

## + Hintergrund

Überall dieselbe Figur (Style-Guide, `docs/style-guide/README.md`, „Szenen und Figuren“);
maßgeblich für das Aussehen ist das Figurenblatt F-01 mit seinem festen Prompt-Baustein im
Bildkatalog. Einen Namen hat er nicht: Der Spieler gibt nur seinem Laden einen, bei der
Gewerbeanmeldung (Feature 010). Das Alter steht als 38 für „Ende dreißig“.
